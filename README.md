# Shuffle Seek · 盲盒寻星

面向手机横屏的盲盒记忆游戏：先展示星星所在的盒子，盖上后交换盒子的位置，再由玩家点击找出星星。

只有首页与棋盘游戏页。首次从第 1 关开始，找到目标后进入下一关，不提供选关入口。所有玩法、关卡与进度都在浏览器本地运行，可作为纯静态网站部署。

> 当前代码已改为记忆追踪玩法。开发代理没有运行项目、构建、编译或类型检查，动画效果与手机实机表现仍需人工验收。

## 玩法流程

1. **记住**：短暂展示星星的初始位置。
2. **盖上**：所有盒子恢复相同外观，目标不再可见。
3. **打乱**：相邻的两个盒子通过动画交换位置，星星随原来的盒子移动。
4. **揭晓**：动画全部结束后，可以点击任意盒子。每轮只有一次选择。
5. **结果**：选中星星则通关并解锁下一关；选错则揭晓正确位置，可无限重试。

“重新观察”会重新随机生成目标位置与交换序列。暂停时停止自动流程和正在进行的交换动画，恢复后继续当前阶段；当前阶段的等待时间重新计算。切后台、窗口失焦或转成竖屏会自动暂停。

键盘用户可在揭晓阶段用 Tab 切换盒子，用 Enter 或空格选择。Esc 暂停，在暂停弹窗中再次按 Esc 继续。

| 2 | 2 × 2 | 4 | 800 ms | 2000 ms |
| 3 | 2 × 2 | 6 | 700 ms | 1800 ms |
| 4 | 3 × 3 | 5 | 750 ms | 2200 ms |
| 5 | 3 × 3 | 7 | 650 ms | 2000 ms |

| 8 | 4 × 4 | 10 | 650 ms | 2200 ms |
| 9 | 4 × 4 | 13 | 550 ms | 1800 ms |

目标盒子至少参与一次交换。真正的交换动画占间隔的 78%，剩余时间用于看清位置；最后一次动画结束前不会开放选择。重试和重玩都重新随机，不复用上一轮答案。

## 技术与结构

React + TypeScript + Vite，Tailwind CSS 4，基于 Radix 的 shadcn/ui Button、Dialog，Lucide 图标。棋盘用可点击的 Button 组件与 CSS 位移动画实现，每个盒子的身份在交换过程中保持不变。

```text
src/
  components/          首页、横屏提示
    game/              盲盒棋盘、阶段提示、游戏页、结果与暂停弹窗
    ui/                shadcn/ui 基础组件
  data/levels.json     十关的棋盘、速度、观察时间与交换次数
  game/                类型、随机开局与交换规则
  hooks/               回合状态、自动暂停、音效、横屏与本地进度
  lib/                 存档与样式工具
```

方向键移动、障碍物、终点和撤销逻辑已移除。关卡越往后，盒子更多、交换更多或更快。

## 运行与检查

建议使用 Node.js 22。首次安装或更新依赖：

```bash
npm ci
npm run dev
```

开发服务监听 `0.0.0.0`。手机与电脑连接同一局域网，访问终端显示的 Network 地址并横屏游玩。若 Windows 弹出防火墙提示，允许 Node.js 在专用网络通信。

需要自行检查类型、打包和预览时：

```bash
npm run typecheck
npm run build
npm run preview
```

`build` 先检查类型，再生成 `dist/`；`preview` 预览已生成的产物。以上命令未由开发代理执行。

## 进度与音效

解锁进度、已完成关卡与音效开关存入 localStorage。刷新后从当前已解锁关卡重新观察，不保留正在进行的回合。新玩法使用独立存档键，不继承旧走格子玩法的关卡进度。

音效由 Web Audio 本地合成，不需要下载音频文件。浏览器存储不可用时会显示提示，仍可在当前页面继续游玩；清除网站数据会清除进度，进度不跨设备同步。

## 手动验收

- 首页点击开始直接进入第 1 关；有进度时显示继续闯关，不出现选关入口。
- 观察阶段能看到目标；盖上后所有盒子外观一致，不能提前选择。
- 交换是真实可跟踪的动画，目标始终跟随同一个盒子；最后一次交换结束后才能点击。
- 任意盒子均可点击；选对只解锁下一关，选错不解锁并显示正确位置。
- 连续快速点击不会多次结算；重新观察生成新回合；暂停时不能选盒，交换不继续播放。
- 切后台或转竖屏后暂停，返回横屏可继续；刷新保留新玩法进度和设置。
- 逐关覆盖 2 × 2、3 × 3、4 × 4 棋盘，以及最后一关的全部通关提示。
- 在 568 × 320、667 × 375、844 × 390 等横屏视口检查棋盘、按钮、弹窗和安全边距。手机触摸和桌面键盘选择都需要验收。

## 静态部署

执行 `npm run build` 后，将 `dist/` 中全部产物上传到静态托管服务。资源使用相对路径，无后端接口和客户端路径路由，无需路由回退。不能直接双击源码 index.html 运行。
