# Shuffle Seek · 平移闯关

一款面向手机横屏浏览器的轻量 2D 方块闯关游戏。在 6 × 6 棋盘上移动蓝色方块，绕开障碍，抵达绿色终点，用简单的方向操作完成路线挑战。

游戏计划采用纯前端静态部署，关卡、游戏逻辑和进度保存均在浏览器本地运行，无需后端服务。

> 当前状态：首版功能代码已实现，尚未安装依赖、运行、构建或执行类型检查；手机实机表现与逐关验收待确认。

## 玩法

- 每次向上、下、左、右移动一格，不能越过棋盘边界或进入障碍格。
- 无效移动不计步，进入终点即通关并解锁下一关。
- 首版提供 10 个关卡，从方向练习逐步过渡到绕障和路线规划。
- 没有倒计时、生命值或失败惩罚，可以自由尝试。
- 支持撤销一步、重置本关、暂停，以及在通关弹窗重玩本关。
- 撤销仅回退最近一次有效移动并扣除一步，不能连续撤销；碰墙不会覆盖撤销记录。

## 移动端横屏优先

- 棋盘保持正方形，操作区位于右侧，方便双手握持操作。
- 支持屏幕滑动与方向按钮，桌面端额外支持键盘方向键。
- 适配屏幕安全区域；竖屏时显示横屏游玩提示。
- 解锁进度与音效设置通过 localStorage 保存在当前浏览器中。

## 技术方案

| 模块 | 计划采用 |
| --- | --- |
| 前端框架 | React + TypeScript |
| 开发与打包 | Vite |
| 棋盘绘制 | Canvas 2D |
| 状态管理 | React 状态 |
| 关卡配置 | 本地 JSON |
| 进度保存 | localStorage |
| 发布方式 | 静态网站托管 |

## 本地运行

建议使用 Node.js 22 与 npm。在仓库根目录依次执行：

```bash
npm install
npm run dev
```

在终端显示的本地地址打开游戏。手机与电脑连接同一个局域网后，可使用终端显示的 Network 地址访问；手机需要允许旋转屏幕。开发服务已配置监听局域网地址，系统防火墙仍可能影响连接。

依赖尚未安装，因此仓库暂未生成 package-lock.json。首次安装后，建议提交生成的锁文件，后续使用 `npm ci` 复现依赖。

需要自行检查类型或打包时执行：

```bash
npm run typecheck
npm run build
npm run preview
```

`build` 会先检查 TypeScript 类型，再打包到 `dist/`；`preview` 用于本地预览已生成的产物。上述命令尚未由开发代理执行。

## 操作说明

- 点击方向按钮，或在棋盘区域滑动至少 24 CSS 像素，每次移动一格。
- 桌面端使用方向键；按住方向键不连续移动。游戏中按 Esc 暂停，暂停弹窗中按 Esc 继续。
- 暂停和通关后不再响应移动；切换后台、窗口失焦或旋转为竖屏时自动暂停。
- 游戏仅有首页和棋盘游戏页，不提供选关入口。首次点击“开始游戏”进入第 1 关，通关后点击“下一关”依次推进。
- 有进度时首页显示“继续闯关”和当前关卡，从最高已解锁关卡的起点继续。
- 音效由 Web Audio 本地合成，在有效移动时触发；不支持音频的浏览器仍可继续游戏。
- 当前棋盘位置不保存，刷新后保留解锁进度、已完成关卡和音效设置。

## 静态部署

执行 `npm run build` 后，将 `dist/` 目录中的全部产物上传到静态网站托管服务。项目使用相对资源路径，无后端接口、无客户端路径路由，不需要服务端路由回退。不要直接双击源码 index.html 运行。

如果使用 GitHub Pages，可将 `dist/` 产物通过 Pages 的发布流程部署；仅推送源码不会自动发布，当前仓库没有配置自动部署。

## 首版范围

专注单机闯关体验，暂不包含账号、服务器、数据库、联机、排行榜、广告、支付、云端存档和关卡编辑器。

浏览器本地存档不会跨设备同步，清除网站数据也会清除已保存的进度。
